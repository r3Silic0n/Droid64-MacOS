DroiD64 is a file manager for disk-images suitable for the Commodore 64 and others. These disk-images are usually stored as .D64 files and have the size of 174848 bytes.

May this tool make life easier for Commodore 64 fans, especially for those using MAC and Linux systems as there are tools available for Windows anyway.

Done from scratch by Wolfram Heyer.
File format structures and 1541 information taken from some fairlight docs at: http://www.fairlight.to/docs/text/formats.zip
Additions, corrections and bug fixes by Henrik Wetterström in 2015 - 2024.

Real disk drive support (OpenCBM)
The CBM dir and d64copy buttons use cbmctrl and d64copy from OpenCBM 0.4.99, which are included in this application, compiled for Apple Silicon. They talk to a real Commodore disk drive (1540, 1541, 1570, 1571) through a XUM1541 USB adapter (also known as ZoomFloppy), so such an adapter must be connected. Parallel port cables (XM1541, XA1541) and the XU1541 adapter are not supported in this build.
